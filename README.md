 🚀Sobre o ProjetoEsta é uma Landing Page conceitual de "Easy Shopping Via Mobile", desenvolvida para simular a apresentação de um aplicativo de compras.
<br>
 O objetivo principal foi criar uma interface altamente escaneável, minimalista e focada na conversão do usuário.
 
 🛠️ Tecnologias e Ferramentas Utilizadas
  
  HTML5: Estruturação semântica do conteúdo.
  
  CSS3: Estilização, sistema de Grid/Flexbox e responsividade.
  
  Google AI (Gemini): Integração de Inteligência Artificial no processo de desenvolvimento para:Refatoração e limpeza de regras CSS duplicadas.

  Otimização de seletores para melhor performance de renderização.Sugestões de boas práticas de design pattern.
